# Third-party skills

The skill folders in this directory were copied from the community project
https://github.com/mukul975/anthropic-cybersecurity-skills (Apache-2.0),
commit 54a798831d2266a3ca61ce68a7acb80b81160d57 (2026-08-31), on 2026-10-08.

It is a community repository, not an official Anthropic release. Only the 13
skills relevant to VulnTriage (vulnerability prioritisation, SBOM, ATT&CK/STIX,
remediation SLAs, RAG prompt-injection testing) were installed out of 818.
Each folder keeps its original LICENSE file. The bundled scripts were not
executed during installation.
